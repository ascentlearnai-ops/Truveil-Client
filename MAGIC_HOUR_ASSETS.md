# Magic Hour production ledger

Truveil Secure uses the same original Magic Hour visual world as the recruiter site while keeping every candidate-facing instruction, consent detail, session code, and status in live HTML.

## Shipped stills

- `assets/generated/candidate-room.jpeg`: quiet private interview desk used as the hero set.
- `assets/generated/privacy-room.jpeg`: sealed glass chamber used beside the privacy disclosure.
- `assets/generated/footer-void.jpeg`: restrained architectural closing image.

These stills were selected from the shared sixty-image 2K Seedream v4 production board. The candidate site intentionally avoids loading the recruiter scroll-flight videos so setup remains fast and calm.

## Runtime rules

- The generated laptop and room establish the physical scene; the Truveil Secure window remains live HTML above it.
- Mobile uses the same responsive stills with adjusted focal points and no video download.
- Invite links continue to replace the installer CTA with `truveil://join?code=...` without changing the generated background layer.
